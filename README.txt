HOW TO USE
1. Extract this zip to your Desktop (right-click > Extract All).
2. Double-click index.html - it opens in Chrome or Edge.
   (Do NOT open it from OneDrive/SharePoint preview - it blocks scripts.)
3. Keep index.html and Abhiram_Rote_Resume_Java_Backend.pdf in the same folder.

THINGS TO TRY ON THE PAGE
- Move your mouse over the background and the hero card.
- Type commands in the terminal: help, skills, projects, resume, sudo hire abhiram

EDIT LATER
- Open index.html in Notepad / VS Code. Text is plain HTML - search for the section you want to change.
- Project GitHub link: search for "View on GitHub" and replace the URL with the exact repo link.

PUT IT ONLINE (free)
- Create a PUBLIC GitHub repo named abhiramrote.github.io
- Upload index.html and the PDF
- Settings > Pages > Deploy from branch (main) -> https://abhiramrote.github.io
